# KlokanTech Noto Sans

These are the non-CJK TrueType faces from KlokanTech Noto Sans v1.0.0:

https://github.com/klokantech/klokantech-gl-fonts/releases/tag/v1.0.0

OpenMapTiles identifies this patched family as the Noto Sans source for its GL
glyphs. The family merges Noto script fonts for multilingual OpenStreetMap
labels. Its upstream name is retained as requested by the project. The embedded
font metadata records `Copyright 2012 Google Inc. All Rights Reserved.`, the
Noto trademark, and the SIL Open Font License 1.1; those notices are reproduced
in `LICENSE` and pinned by `fonts_test.go`. The original project description and
family-name attribution request are preserved verbatim in `UPSTREAM-README.md`.
